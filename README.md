# Относительная информативность декомпозированных и полных мер неопределённости

Код и результаты к статье

> И.А. Кистин, Ш.М. Исаев. Относительная информативность декомпозированных и
> полных мер неопределённости: совместная зависимость от сдвига распределения
> и режима обучения // Научно-технический вестник информационных технологий,
> механики и оптики. (в печати)

Репозиторий содержит всё, что нужно для воспроизведения численных результатов
и рисунков статьи: реализацию байесовской свёрточной сети, три эксперимента,
сохранённые сырые оценки неопределённости и скрипты, строящие таблицы и
рисунки статьи из этих оценок.

## Быстрый старт

```bash
python -m pip install -r requirements.txt
cd src

python core.py    --seeds 0 1 2 3 4     # эксперимент A — межнаборный сдвиг
python shift.py   --seeds 0 1           # эксперимент B — повороты
python regime.py  --seeds 0 1           # эксперимент C — режим обучения

python tables.py                        # печатает все таблицы статьи
python figures.py                       # строит рис. 1-4
```

Наборы данных загружаются автоматически в `src/data/`. Расчёт выполнялся на CPU;
GPU не требуется. Один сид эксперимента A занимает около 8 минут на двух ядрах.

Каталог `results/` уже содержит результаты, на которых построена статья, поэтому
`tables.py` и `figures.py` можно запускать сразу, без повторного обучения.

## Что и как считается

Байесовская свёрточная сеть обучается стохастическим вариационным выводом со
средним полем. Предсказательное распределение оценивается усреднением по `S`
выборкам из вариационного апостериорного распределения весов, после чего полная
предсказательная энтропия раскладывается на две составляющие:

```
H[p̂(y|x*)]  =  (1/S) Σ_s H[softmax(f(x*; w_s))]  +  I(y; w | x*, D)
   полная            алеаторная (U_alea)              эпистемическая (U_epi)
```

Все энтропии считаются натуральным логарифмом и выражены в натах — в тех же
единицах, что KL-член ELBO и взаимная информация. Оценка `U_epi` смещена вниз
при малых `S`: при `S = 1` она тождественно равна нулю.

Сравниваются четыре меры: максимум softmax (базовая оценка), полная энтропия,
алеаторная и эпистемическая составляющие. Качество обнаружения — AUROC
(внешнее распределение считается положительным классом; для максимума softmax
знак признака инвертируется) и FPR@95TPR. Обе метрики не зависят от порога.

## Эксперименты

| Скрипт | Эксперимент | Внутреннее распределение | Внешнее распределение |
|---|---|---|---|
| `core.py` | A — межнаборный сдвиг | FashionMNIST, test | MNIST, test |
| `shift.py` | B — внутридоменный сдвиг | FashionMNIST, test | тот же набор, повёрнутый на 15–180° |
| `regime.py` | C — режим обучения | FashionMNIST, test | MNIST, test, сетка эпохи × масштаб априора |

Эксперимент B устроен парно: внешнее распределение получается преобразованием
тех же объектов, что и внутреннее.

## Данные и предобработка

* **Источник.** `torchvision.datasets.FashionMNIST` и `torchvision.datasets.MNIST`,
  загрузка автоматическая при первом запуске. Версия наборов фиксируется версией
  torchvision из `requirements.txt`.
* **Предобработка.** `ToImage → ToDtype(float32, scale=True) → x·2 − 1`,
  то есть приведение к диапазону `[−1, 1]`. Аугментаций нет.
* **Разбиение.** Обучение только на train-части FashionMNIST (60 000 объектов),
  оценивание — на test-частях (по 10 000). Пересечения выборок нет.
  Отдельной валидационной подвыборки нет; это оговорено в разделе «Ограничения»
  статьи.
* **Повороты (эксперимент B).** `torchvision.transforms.v2.functional.rotate`,
  углы 15, 30, 45, 60, 90, 120, 150, 180°, поворот вокруг центра изображения,
  интерполяция по умолчанию (nearest), фон заполняется значением `−1`
  (соответствует чёрному после нормировки). Преобразование применяется к уже
  нормированным тензорам, то есть предобработка внутреннего и внешнего
  распределений идентична.

## Гиперпараметры

Совпадают с разделом «Экспериментальная установка» статьи.

| Параметр | Значение |
|---|---|
| Свёрточные слои | 1→16 и 16→32, ядро 5×5 без дополнения, max-pooling 2×2 |
| Полносвязные слои | 512 → 256 → 10, ReLU |
| Априорное распределение | `N(0, σ²I)`, `σ = 1` (базовая конфигурация) |
| Вариационное семейство | `AutoDiagonalNormal` (Pyro) |
| Оптимизатор | Adam, темп обучения `2e-3` |
| Размер мини-батча | 128 |
| Число эпох | 5 (базовая конфигурация) |
| Оценка ELBO | `Trace_ELBO`, правдоподобие масштабируется множителем `N/B` |
| Выборок при оценивании | `S = 50` |
| Сиды | задаются явно ключом `--seeds` |

В эксперименте C варьируются число эпох (5 и 20) и масштаб априорного
распределения (`σ = 1,0` и `0,1`); остальные параметры неизменны.

## Воспроизводимость

Фиксируются три независимых источника случайности: инициализация вариационных
параметров (`pyro.set_rng_seed`, `torch.manual_seed`), перемешивание обучающей
выборки (`torch.Generator`) и выборка весов при оценивании. При одинаковом сиде
и одинаковых версиях библиотек результат воспроизводится побитово.

Разброс между запусками для этой модели велик и сам по себе является результатом
статьи: по пяти сидам AUROC полной энтропии меняется от 0,541 до 0,780, тогда как
AUROC эпистемической составляющей — лишь от 0,928 до 0,966. Одиночный запуск
не характеризует ни одну из мер, поэтому все результаты приводятся как средние
по нескольким сидам с доверительными интервалами.

## Структура

```
src/core.py      модель, обучение, декомпозиция, метрики; запуск = эксперимент A
src/shift.py     эксперимент B — повороты
src/regime.py    эксперимент C — сетка режимов обучения
src/tables.py    печатает таблицы 2-7 и П1-П3 статьи из results/
src/figures.py   строит рисунки 1-4 из сохранённых сырых оценок
src/roc_utils.py ROC-кривые и AUROC для figures.py
results/*.json   метрики по запускам
results/*.npz    сырые значения неопределённости для каждого объекта
figures/         сгенерированные рисунки
```

Файлы `results/scores_seed*.npz` содержат по четыре массива на каждое
распределение (полная энтропия, алеаторная и эпистемическая составляющие,
максимум softmax) и историю ELBO. Рисунки строятся именно из них, а не
сохраняются вручную.
